============================================================
2. ¿QUÉ ES ÚTILHUB?
============================================================

ÚtilHub es una plataforma de herramientas útiles para el
día a día.

Incluye herramientas de cálculo, conversión, organización,
productividad, texto, compras, comidas y otras funciones.

La versión V17 incorpora NOVA FLOW con diferentes modos
visuales que el usuario puede seleccionar.

------

sw.js


PASO 3
------

En GitHub entra a:

Settings
   ↓
Pages
   ↓
Build and deployment
   ↓
Source
   ↓
Deploy from a branch


Selecciona:

Branch: main
Folder: / (root)


Pulsa:

Save


============================================================
5. ABRIR ÚTILHUB
============================================================

Después de publicar GitHub Pages, GitHub proporcionará una
dirección parecida a:

https://TU-USUARIO.github.io/UtilHub-V17/


La dirección exacta dependerá del nombre de tu cuenta y
del repositorio.


============================================================
6. INSTALAR COMO APP
============================================================

ÚtilHub V17 utiliza:

manifest.webmanifest
sw.js

En navegadores compatibles aparecerá la opción para instalar
la página como aplicación.

En computadora puede aparecer como:

Instalar ÚtilHub


En celular puede aparecer como:

Añadir a pantalla de inicio

o

Instalar aplicación


La disponibilidad depende del navegador.


============================================================
7. FUNCIONAMIENTO SIN INTERNET
============================================================

El Service Worker guarda los archivos principales de ÚtilHub.

Esto permite que algunas partes continúen funcionando cuando
no exista conexión.

Las herramientas que necesitan servicios externos pueden
requerir Internet.


============================================================
8. DATOS DEL USUARIO
============================================================

Las configuraciones y determinados datos de ÚtilHub se
guardan localmente en el navegador mediante localStorage.

Esto permite conservar preferencias como:

- Tema
- Modo NOVA FLOW
- Favoritos
- Herramientas recientes
- Notas
- Tareas
- Configuraciones


============================================================
9. ACTUALIZAR ÚTILHUB
============================================================

Cuando publiques una nueva versión:

1. Modifica los archivos.
2. Guarda los cambios.
3. Súbelos a GitHub.
4. Espera a que GitHub Pages publique los cambios.
5. Recarga ÚtilHub.


============================================================
10. RECOMENDACIÓN
============================================================

No cambies los nombres de los archivos principales:

index.html
style.css
script.js
manifest.webmanifest
sw.js

Si cambias alguno de estos nombres, también tendrás que
actualizar las referencias correspondientes.
